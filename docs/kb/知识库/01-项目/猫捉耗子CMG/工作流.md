# 《猫捉耗子 CMG》资产生产工作流（Agent 驱动版）

> 最后更新：2026-09-21。资产从「生图」到「进游戏」已全自动闭环。

## 一条线
定风格（一次）→ 网页生图 → 丢收件箱 → 跟 Agent 说一句话 → Godot 接线 → 验收

## 步骤
### ① 定风格（一次性）
出「定妆照」→ 配色回填 art-bible.md 调色板

### ② 生图（网页，手动）
按 art-bible.md 第 4 节模板：ChatGPT（真透明，定稿首选）/ Gemini（纯洋红底，仅概念）
下载 → 放进 kb/知识库/00-收件箱/assets/

### ③ 跟 Agent 说一句话
例：「处理收件箱里的猫精灵表，命名 cat_run」
Agent 会：kb_read art-bible → asset_pipeline → 自动抠图/切帧/对齐/预览/入库

### ④ Godot 接线
按自动生成的 cmg/assets/sprites/<名称>_接入说明.md 接 AnimatedSprite2D

### ⑤ 验收迭代
看 Download/imgart/<名称>/<名称>-check.png；不过 → 改提示词重出

## 兜底（Agent 抽风时手动跑）
cd ~/agent && python imgart.py pipeline <原始图> <名称>

## 工具一览（~/agent/imgart.py）
probe / sheet / key / slice / anchor / ingest / pipeline

## 产物位置
- Download/imgart/<名称>/frames/、final/、<名称>-check.png
- cmg/assets/sprites/<名称>_NN.png + 接入说明.md
