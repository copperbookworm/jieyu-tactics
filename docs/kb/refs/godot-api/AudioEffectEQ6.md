**摘要**：Adds a 6-band equalizer audio effect to an audio bus. 		Gives you control over frequencies from 32 Hz to 10000 Hz. Each frequency can be modulated between -60/+24 dB.

## 描述

Frequency bands:
		Band 1: 32 Hz
		Band 2: 100 Hz
		Band 3: 320 Hz
		Band 4: 1000 Hz
		Band 5: 3200 Hz
		Band 6: 10000 Hz
		See also `AudioEffectEQ`, `AudioEffectEQ10`, `AudioEffectEQ21`.
