# 价格清单怎么发布（让「改价不发版」真正生效）

## 一句话

把 `tools/price_manifest_build.gd` 生成的 json 放到一个公开 **https** 地址，
再把地址填进游戏（面板 → ④ 用量账单 → 「价格清单 URL」）。以后改价只要更新那个文件，**不用重新发版**。

## 为什么这块要你自己托管

模型名能靠供应商官方的「列出模型」接口现取，但**「多少钱」没有同类接口**
（OpenRouter 的 `/models` 里带 pricing，DeepSeek / OpenAI 都不带）。
所以价格的更新源只能是一份**你自己的静态文件** —— 纯静态、不含密钥、也不代理玩家的 key。

## 三步

### 1. 生成

```powershell
& "<Godot console exe>" --headless --path "D:\Godot4.7_Proj\jieyu-1" ^
  --script res://tools/price_manifest_build.gd -- ^
  --version=3 --updated=2026-10-05 --source=https://… --out="D:\Godot4.7_Proj\price_manifest.json"
```

- `--version` **必须大于内置 `AiPriceTable.VERSION`**。游戏侧是「版本只能升不能降」，
  平版或更旧会被整份拒绝（这是为了防止一次误操作把玩家看到的价格退回旧价）。
- 生成器**生成后会用同一套规则回读一遍**，所以「生成成功」本身就等于「格式合法」。
- 也可以只打印到 stdout（不传 `--out`），自己重定向存盘。

### 2. 发布（任选其一）

| 方式 | 说明 |
|---|---|
| 静态站点 / 对象存储 | 直接把 `price_manifest.json` 传上去，拿到 https 直链 |
| GitHub / Gitee 仓库 | 传进仓库，用 raw 链接 |
| 加 CDN（推荐） | jsDelivr 走仓库：`https://cdn.jsdelivr.net/gh/<user>/<repo>@<tag>/price_manifest.json`，带缓存、国内一般可达 |
| 自建 / 局域网 | **唯一允许的 http 例外是回环地址**（`http://127.0.0.1`、`http://localhost`），那是本机自测/自建用的 |

### 3. 填进游戏

面板 → ④ 用量账单 → 「价格清单 URL」→ 粘贴 → 点「更新价格表」。
地址存在 `ai_advisor.cfg` 里，**不用重新打包**（玩家自己也能改）。

## 以后改价

改 `systems/ai/AiPriceTable.gd` → 把 `VERSION` 加一 → 跑一次生成器 → 覆盖已发布的文件。
玩家下次开面板会自动拉（24 小时缓存），也可以点「更新价格表」立刻拉。

发布前想再核一遍就跑：

```powershell
… --script res://tools/price_manifest_build.gd -- --check="D:\Godot4.7_Proj\price_manifest.json"
```

## 游戏侧会怎么处理这份清单

- **只接受 https**（回环除外）：http 明文清单能被中间人换成任意价格
- **严格校验**：schema 版本、币种、两个时段齐全、费率必须是 0 ~ 10_000_000_00 微元/百万 token 的整数、
  条数上限 256；多余或不合格的字段直接拒绝
- **版本只能升不能降**：清单 `version` 比内置旧 ⇒ 整份不采纳
- **校验不过 ⇒ 保持原样**，只在面板写一行原因；**绝不半采纳**
- **只在「AI 参谋已开启」且「已填 key」时才去拉** —— 面板上写着「不填 key 就完全不联网」，
  这条承诺不能被自己破掉。默认地址是**空的**，所以默认就是零联网
- 请求**不带 key、不带任何玩家标识**，只是一个 GET
- 缓存在 `user://ai_usage/price_manifest.json`（原文 + 抓取时间），24 小时过期；
  **离线启动也会先用缓存**，所以更新过的价不会因为断网就丢
- 账本每一笔都记 `price_version`（生效版本）与 `price_source`（`bundled` / `remote`），
  以后玩家拿着旧账对不上新价时能说清楚

## 安全边界（说清能做到什么、做不到什么）

- 清单**只影响显示用的估算**，不参与计费、也不进游戏状态；估算本身就标着「估算」
- 但它确实能改玩家看到的金额 ⇒ **别提交错的价**；费率上限与严格校验主要就是为防笔误
- 清单地址**玩家可改**（面板里能填）⇒ 它只是「维护者给的参考价」，不是权威数据源；
  真实账单永远以供应商为准
- 清单是**公开文件**：不要往里面写任何不该公开的东西（它本来就只该有价格）
