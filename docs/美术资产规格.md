## 一、命名与目录硬规则

| 规则 | 说明 |
|---|---|
| 全小写 + 下划线 | `char_rifleman_base` ✅ ／ `角色-步枪兵` ❌ |
| **不许中文文件名** | 跨平台导出最容易在这里出事（门禁会红） |
| 帧序号补零两位 | `char_lower_walk_01.png` … `_08.png`，否则排序会错 |
| 同名不同用途要区分 | `_base` / `_hurt` / `_dead`，不要靠目录区分 |
| 文件名不带尺寸 | 改尺寸不用改名（尺寸写在规格里） |
| 目录 | 角色 `assets/chars/`｜载具 `assets/vehicles/`｜地图 `assets/maps/`｜UI `assets/ui/`｜特效 `assets/fx/`｜图标 `assets/icons/`｜单位 `assets/units/` |

## 四、怎么校验（每次入库前跑一次）

```powershell
$g = "E:\Godot_v4.7.1-stable_win64.exe\Godot_v4.7.1-stable_win64_console.exe"
& $g --headless --path "D:\Godot4.7_Proj\jieyu-1" --script res://tools/check_art_manifest.gd
# 要硬查「第一批 14 张必须全部到位」时：
& $g --headless --path "D:\Godot4.7_Proj\jieyu-1" --script res://tools/check_art_manifest.gd -- --require-batch1
```

- **退出码只反映「规格文件自己是否自洽」**：ID 唯一且 snake_case、路径都在 `res://assets/` 下、
  无中文文件名、尺寸要么正整数对要么显式 `null`、batch1 每一项都已给出尺寸。
- **素材到货数量只打印、不算失败** —— 资产是一张一张来的，「第 N 张还没来」不是工程坏了。
- 它同时是单元测试跑批里的**第 4 条门禁**（3 条几何 ＋ 1 条美术规格）。

## 五、入库注意

1. 纹理过滤是 **Nearest**（`default_texture_filter=0`）—— 像素风资产**不要**做抗锯齿/插值，否则糊。
2. **`.import` 文件要一起进版本库**（它是导入设置，不是缓存）。
3. 入库后**跑一次测试**：`--headless --script res://tools/run_tests_headless.gd`，确认没有脚本因资源路径变化而红。
4. **只有真的以 PNG 入库了**，才更新设计表的 `状态` 列 —— 「程序画的」≠「PNG 资产已完成」。
