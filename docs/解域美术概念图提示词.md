# 《解域》美术概念图生成提示词（2026-10-08）

用途：给美术 / AI 出图工具（Midjourney、SDXL、Flux、Nano Banana 等）生成**一张能代表《解域》整体面貌的概念图**（Key Art / 定妆图）。
与 `tools/asset_prompts.py` 的关系：那个是**逐条资产**的提示词（98 条，管线用）；本文件是**整张概念图**的提示词，用来定「这套游戏长什么样」，出图后应反过来当 reference 喂给逐条资产，保证成套。

---

## 二、出图前必须钉死的 6 条纪律

1. **视角不许歪**：一旦出现等轴测（isometric）、斜俯视、鸟瞰带透视，画风就不再是《解域》——俯视是正交垂直向下（90°），地面没有灭点。
2. **不写实**：不要照片级、不要 3D 渲染、不要 PBR 金属反射。要扁平分色 + 硬边 + 克制的细节。
3. **不画不可见的东西**：本作「未通过通视检测的敌人一律不绘制」。概念图是美术表达可以放宽，但**不要画成全员大混战**——战术感来自「看得见什么、看不见什么」。
4. **禁止真实军事标识**：不得出现真实国旗、军徽、部队番号、真实装备型号字样（合规红线，见十七）。
5. **图里不要文字**：所有文案后期在工程里排（`STYLE_UI` 的 `no text` 纪律一致）。
6. **成套**：定妆图出来之后，把它当 reference 喂给 `tools/asset_prompts.py` 的逐条提示词，**同模型 + 同 seed**，否则同一个兵种会出现三种画风。

## 五、推荐参数

| 项 | 建议 |
| --- | --- |
| 画幅 | 16:9（与 960 × 540 一致）；推荐出 1920×1080 或 2560×1440 再缩绘 |
| 一次出几张 | 4 张挑 1 张当定妆图（reference），其余 3 张只作构图参考 |
| Midjourney | `--ar 16:9 --style raw --stylize 250 --seed <固定>` |
| SDXL / Flux | CFG 4.5–6、30 步、`flat vector / cel shading / hard edges` 强化词（已写进正文）；开透明无关（本图不透明满幅） |
| 商用授权 | 与 `asset_prompts.py` 同一纪律：**只商用授权的模型**，保留出图记录（模型 / seed / 参数） |
| 出图后 | 缩到 960×540 检查一次「可读性」：单位是否还认得出、掩体是否读得出高度、阵营色是否一眼可分 |

## 六、这套概念图的验收标准（可直接当检查表）

- [ ] 俯视是**正交垂直向下**，画面里找不到灭点与透视边。
- [ ] 缩到 960 × 540（＝游戏实际画布）后，士兵与载具仍能一眼分辨阵营与朝向。
- [ ] 画面里**没有文字、没有真实军事徽记与型号**。
- [ ] 掩体高度看起来都在胸口以上；视线被至少 2 处山脊 / 建筑群 / 树林带打断。
- [ ] 阴影只有**一个**光照方向，且阴影是扁平椭圆、形状不随动作扭动。
- [ ] 主色落在橄榄绿 + 暗石板灰 + 干黄浅褐范围内；除了阵营色与 `#7bd88f` 没有高饱和色。
- [ ] UI 层（状态面板 / 小队列表 / 小地图）是薄薄一层暗色半透明，不遮挡战场主体。
- [ ] 一眼能读出「五节点推进 + 白旗点争夺」的战术结构，而不是一张普通的枪战插画。

## 七、不属于本提示词的（别拿 AI 出图顶替）

- **灰度高度图**：它是数据通道（白高黑低，0–255 映射 0–150 m），套上赛璐璐画风等于毁数据。用 World Machine / Gaea 或地图工具链（`addons/jieyu_map`）产出。
- **地形 Tile / 等高线层**：需要无缝平铺、无烘焙光照方向，用 `STYLE_MAP` 那条，不要用本文件的整图提示词。
- **UI 九宫格与摇杆**：纯色块类直接用矢量工具画更准（能定 9-slice 边距），AI 只用来打底。
- **数值与尺寸**：提示词里写的 0.5 m 肩宽 / 8.3 m 车长 / 32 PPU 是**约束**，最终以 `assets/spec/art_manifest.json` 与 `tools/check_art_manifest.gd` 门禁为准。
