一、整体架构（分层）

① 入口 / 装配层代码装配，场景文件只有空节点 —— 不手改 .tscn
Main.tscn → Main.gd
唯一主场景。地形/玩家/敌人/载具/HUD 全在 _ready() 里 new 出来；也是地图预览模式的开关所在
core/SceneManager·GameManager·GameState·InputManager·SaveManager
零引用模板脚本（grep 核实），当前流程不经过它们
② 数据层（表驱动）数值不进代码，进表
GameConfig.gd
全局常量总表：武器衰减、散布、姿态、压制、载具、相机、UI 坐标
RoleTable.gd
3 兵种（步枪兵/侦察兵/精确射手）→ 武器、标记时效、伤害倍率
weapons_data.txt + WeaponTable.gd
5 把枪（含官方表抄录列）；曾是 .csv，被 Godot 当翻译表导入，故改 .txt
vehicles_data.txt + VehicleTable.gd
ifv_a / mbt_t1；命中面判定、等效厚度 = 法向厚度 ÷ cos(偏角+倾角)、击穿判定
quest_templates.txt + QuestTable.gd
3 条可发模板（T-M1 / T-S4 / T-S1）；其余 5 条不可发理由写在脚本头部
③ 系统层（纯逻辑，多数可脱离场景测试）
systems/terrain
HeightGrid（1 m 高程网格）/ MapGenerator（噪声＋灰度图导入）/ SightSystem（DDA 逐格通视、地形＋掩体＋烟）/ MapInspector（可达性与通视探针）
systems/combat
BallisticsSystem（直瞄射线／带阻力间瞄解算）/ CaptureZone（净进度 −1..1 状态机）/ IndirectFire / SuppressionSystem / Tracer
systems/marks · quest
MarkSystem（6 类标记、30 s 时效）/ QuestSystem（主线＋≤2 支线、权重表、时限）
systems/camera
AimCameraController：准心＝屏心＝相机中心；右半屏起手接管；三档离散缩放
systems/weapons · vehicles
WeaponTable / VehicleTable：读表 + 查询纯函数（刻意无 class_name，引用方 preload）
systems/ai/AISystem · combat/CombatSystem · combat/DamageSystem · inventory/*
零引用占位。敌人 AI 实际写在 entities/enemy/Enemy.gd 里
④ 实体层（场上会动的东西）
entities/player/Player.gd
移动、姿态三态、散布（动静二分×聚焦×压制）、弹匣/换弹/切枪、血量与视线眼高
entities/enemy/Enemy.gd
AI 状态机（巡逻→发现→交火）、还击散布受压制影响、停火犹豫、压制弧表现
entities/cover/Cover.gd
可旋转、可破坏掩体（沙袋 ×12），兼作 occluder
entities/vehicle/Vehicle.gd
双座位、炮塔与车体分离＋回正、后坐、装甲挨打、主炮开火、AI 驾驶（本会话修：后坐沿炮管轴向、准心箭头取炮塔朝向、未击穿提示带数值）
EnemyGoblin.gd / EnemySlime.gd / PlayerStateMachine.gd
零引用残留（前者只剩一句 print），待清理
⑤ 表现层（CanvasLayer HUD 全部代码生成）
VirtualJoystick
左下角摇杆（圆心 100,440、半径 90、触摸判定 144 px）——左侧 UI 一律避让此区
FireButton · FocusButton
开火；按住式聚焦（收窄准心＋边缘暗角）
MiniMap · TacticalMap · MapPreview
小地图／全屏战术图（开图不暂停）／地图预览模式（含本会话新增的载具标记）
MarkWheel · MarkOverlay · QuestCard · IndirectOverlay · DebugEnemyArrow
报点环、标记渐隐、任务卡片、间瞄落点预警圈、敌方方位箭头
⑥ 校验层20 个 @tool EditorScript：脚本编辑器打开 → 文件 → 运行
test/*.gd
terrain / ballistics / capture / cover / crosshair / handling / height_image / indirect / map_inspector / mark / quest / role / suppression / tactical_map / vehicle / weapon …
tools/*.gd
build_scenes（生成场景，不手写 .tscn）、export_height_map（噪声地形导出起手稿）
gdtoolkit/ · .gdlintrc
gdlint 静态检查；max-file-lines 已放宽到 1200（Main.gd 已 1002 行 —— 借账）
