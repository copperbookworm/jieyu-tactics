## 二、怎么出包

```powershell
# 0) 先问「现在能不能发」——改工程、不出包，13 项关键检查
& "D:\Godot4.7_Proj\jieyu-1\tools\android_overrides\release_check.ps1"

# 1) 出 AAB（自动：跑测试 → 关掉 Godot 自带签名 → 导出未签名包 → jarsigner 签 → splash 补丁 → 复核签名 → 还原预设）
& "D:\Godot4.7_Proj\jieyu-1\tools\android_overrides\export_android.ps1" -Mode release -Format aab `
    -Out "D:\Godot4.7_Proj\APK\jieyu-0.1.0.aab"

# 2) 出 APK（装真机复测用；不是上架件）
& "...\export_android.ps1" -Mode release -Out "D:\Godot4.7_Proj\APK\jieyu-0.1.0.apk"
```

- **格式在哪里切**：AAB/APK 由 `gradle_build/export_format` 决定，而它存在 preset 里。
  为了不维护两份 230 行的重复预设，包装脚本在**导出窗口内**临时改成 1、导出后在 `finally` 里还原；
  崩溃残留会在下次运行开头自愈（`_release_cfg_backup/`）。
- **验收看三条**：脚本打印的 **SHA256 / 签名 DN / 证书指纹**；DN 里出现 `O=Stichting Godot` 就说明签的是 debug 证书，直接报错退出。
- 产物级复核（任意 APK/AAB）：`skills/release-engineering-android/scripts/verify_artifact.ps1`。

## 七、实测结论：Godot 4.7.1 自带的 release 签名链在本机接不通（2026-10-07 第八十七版）

### 现象

export_presets.cfg 里 keystore/release、keystore/release_user、keystore/release_password 三样**都读得到**
（写了个 extends SceneTree 的小脚本，在**导出窗口内**用 ConfigFile.load() 逐键打印确认过），
keystore 文件存在、keytool -list -storepass 能打开、别名 jieyu 在、中文/英文 locale 都试过 ——
但导出仍然报：

```
ERROR: 代码签名: 找不到发布密钥库，无法导出。
ERROR: Project export for preset "Android" failed.
```

换成 res:// 工程内路径、相对路径、反斜杠路径、APK（非 AAB）**全都一样失败**。

### 根因（verbose 日志给的证据）

加 --verbose 之后能看到 Godot 交给 Gradle 的命令行：

```
gradlew.bat validateJavaVersion clean bundleStandardRelease ... -Pexport_package_name=... -Pperform_signing=true
```

**-Pperform_signing=true 后面一个 keystore 属性都没有**（正常应带 -Pkeystore_file / -Pkeystore_password 之类）。
也就是说：preset 里那三项它读到了，但**没有接到它自己那条签名链上**，于是既没签名、又提前报错。

### 采用的做法：把签名显式化（本项目从此的长期口径）

- 导出窗口内把 package/signed 改成 false，让 Godot **只出未签名包、完全不碰签名**；
- 导出后由我们自己签：**AAB 用 jarsigner**（v1 JAR 签名，Play upload key 的标准做法）、
  **APK 用 apksigner**（v1+v2+v3，Android 11+ 需要 v2）；
- 复核也换成不依赖语言的方式：jarsigner -verify 看**退出码**（0 = 通过）+ 证书 CN。
  ⚠ 不能用英文关键字（jar verified）判断 —— jarsigner 输出是本地化的，中文 JVM 上会假红（本轮误报过一次）。

### 顺带修掉的老坑：导出「假死」

GradleDaemon 会继承导出进程的 stdout 管道且不释放 ⇒ 用管道读 Godot 输出的脚本永远等不到 EOF，
表现为「包已经写好、脚本却一直 running」（AGENTS.md 记过，有一次拖了 24 分钟）。

- ❌ **不要**用 gradle.properties 的 org.gradle.daemon=false 来治：关掉之后 java 进程就是**构建 JVM**，
  看门狗一 kill 就当场打断构建（gradle 报「Android 项目构建失败」，白出一枚坏 AAB）—— 本轮实测踩到。
- ✅ 保留 daemon，由 export_android.ps1 的看门狗在**产物写好并稳定 90 s 后**，只收命令行含 GradleDaemon 的**空闲**进程。

### 另一个环境坑

本机环境同时有 NO_PROXY 与 no_proxy，PS 5.1 的 Start-Process 会抛
「已添加项。字典中的关键字:NO_PROXY」。导出脚本因此改用 .NET Process 直接起进程。

## 十一、用 bundletool 把 AAB 装到真机（release 回归，2026-10-07 第九十二版）

Play 收的是 **AAB**，而真机上直接装不了 AAB —— 必须用 `bundletool` 从 AAB 生成设备可装的 APK。
本轮把这一步跑通了，**这才算 release 包真机回归**（此前只回归过自己出的 APK）。

**工具**：`bundletool-all-<版本>.jar`（standalone，带 Main-Class）。
⚠ Gradle 缓存里的 `bundletool-1.16.0.jar` 是**库**不是 standalone，直接 `java -jar` 会报
「没有主清单属性」——别在那个文件上耗时间。可从 GitHub releases 下 `bundletool-all-*.jar`。

```
# 1) AAB -> 设备可装的 APK（universal 模式：一个包通吃所有 ABI/密度）
java -jar bundletool-all-1.16.0.jar build-apks \
  --bundle=jieyu-0.1.0.aab --output=jieyu.apks --mode=universal --overwrite \
  --ks=D:\keys\jieyu-release.keystore --ks-pass=pass:<口令> \
  --ks-key-alias=jieyu --key-pass=pass:<口令>

# 2) 解开 .apks（就是个 zip）取出 universal.apk
#    PowerShell： [System.IO.Compression.ZipFile]::ExtractToDirectory('jieyu.apks','_univ')

# 3) 装真机 + 启动（与普通 APK 一样）
adb install -r _univ/universal.apk
adb shell am start -n io.github.copperbookworm.jieyu/com.godot.game.GodotAppLauncher
```

**本轮结果**：`build-apks` 退出码 0；universal.apk 33.8 MB；
`apksigner verify` 给出 `CN=JIEYU Release, OU=Game, O=copperbookworm, C=CN`；
装进 PCE-W30 后进对局正常（高度图 / 235 个掩体 / 58 片内容层 / 3 个白旗点全对），**无 SCRIPT ERROR、无 FATAL EXCEPTION**。

> 口令从 `D:\keys\jieyu-release-PASSWORD.txt` 读，**不要**写进任何脚本或命令历史。

## 十、发布包体与 export 过滤（2026-10-07 第八十九版 · 真机验收抓到的）

**问题**：`export_presets.cfg` 里 `export_filter="all_resources"`、`exclude_filter=""` ⇒ 工程里**任何**文件都会进包。
`shots/`、`_verify_android/` 这些**验证截图**（2880×1920）被 Godot 导入成 `.ctex`，**一张就 3.4 MB**，
包内 `assets/.godot` 一度到 **43.7 MB** —— 比游戏本体资源还大。第 87 版那枚 38.3 MB 的 AAB 也是这么虚胖起来的。

**修法**（已写进 preset）：

```
exclude_filter="res://shots/*,res://_verify_android/*,res://_touch/*,res://docs/*,res://test/*,res://tools/*,res://_*.log,res://_*.txt,res://*.md"
```

效果：同一份代码，**69.8 MB → 30.3 MB（2.3×）**。

**纪律**：

- 以后往仓库里放截图（`shots/`、录屏、临时对比图）**都必须确认它落在 exclude 里**；
  证据该进 git，但**不该进玩家的包**。
- 出包后养成看一眼包内大头的习惯（本次就是靠 `zipfile` 按目录聚合才一眼看到 `assets/.godot` 43.7 MB）。
- `exclude_filter` 里**不要**写 `#` 注释 —— 见第七节。
