## 1. 发布说明（玩家能做什么）

- 选「工程兵」开局（兵种键循环到第 4 个），HUD 标签上多出「爆破 N 发」。
- 按「爆破」= **按距离自动分两种打法**（不新增按键）：
  - **≤ 15 m 贴放**：在准心落点贴一枚，但要先**安放读条 1.5 s**（站住别动）。
  - **> 15 m 投掷**（最远 35 m）：抛物线飞过去，飞行中一直画着**落点预警圈**（红圈 + 十字）。
- 再按一次「爆破」= **遥控起爆**：半径内的掩体 / 建筑扣结构值，半径内的单位吃爆炸伤害。
- 读条中**移动 / 开火 / 挨打 / 开图 / 上车**都会打断：打断**不消耗发数**，可以重来。
- 飞行中的药按「爆破」会被拒绝（"还在飞"），落地后才让起爆。
- **一次只能有一枚待爆药**：放了一枚还没炸，再按是引爆而不是再放一枚。
- 非工程兵按它只会得到一句提示；工程兵两发放完也会提示。
- **自伤跟本局模式走**（㊺）：竞技 / 困难（开友伤）贴脸放 ＝ 自杀；休闲 / PVEVP（关友伤）只伤敌。

## 2. 数值（唯一出口 = `data/config/ChargeTable.gd`）

| 装药 | 结构伤害 | 对人（爆心 / 半径处） | 半径 | 说明 |
|---|---|---|---|---|
| **C4**（默认） | **1500** | 120 / 40 | 8 m | 工程兵默认装药；加固档建筑 3000 正好两发 |
| TNT | 2000 | 160 / 55 | 9 m | 拍板给的更重一档；第一版只进表（换装药改一行数据） |

锚点：一栋**标准建筑（1200）一发 C4 就没了**；加固档（3000）两发；沙袋（200）贴上去必碎。
对比：155mm 间瞄 420、反坦克导弹 800 —— 炸药是「贴上去」的那一档，贵的是**人得走到那儿**。

射程与时间（唯一出口 = `systems/explosives/ExplosiveSystem.gd` 的常量）：

| 常量 | 值 | 说明 |
|---|---|---|
| `PLACE_MAX_M` / `THROW_MIN_M` | 15 m | 贴放上限**同时**是投掷下限（分档不留缝） |
| `THROW_MAX_M` | 35 m | 再远拒绝（会返回原因，不是静默失败） |
| `PLACE_CAST_S` | 1.5 s | 安放读条 |
| `CAST_MOVE_TOLERANCE_M` | 0.75 m | 挪出这么多米才算「移动了」（操作抖动不算） |
| `THROW_FLIGHT_BASE_S` / `_PER_M` | 0.5 s / 0.03 s·m⁻¹ | 15 m → 0.95 s、35 m → 1.55 s |
| `THROW_ARC_MIN/MAX_PX` | 12 / 40 px | 抛物线抬升的**屏幕**峰值（俯视 2D 没有真实高度轴） |

## 3. 输入 / 状态 / 输出

| 项 | 内容 |
|---|---|
| 输入 | HUD「爆破」键（`ExplosiveButton`，(700,340)）→ `ExplosiveController.toggle()`；开火键的 `fired` 信号另接 `notify_fired()`（打断读条） |
| 状态 | `placed`（待爆的那一枚，`entities/explosive/Charge.gd`）、`used`（本局已放发数）、读条现场四件套（`_casting` / `_cast_left` / `_cast_origin` / `_cast_target` / `_cast_hp`） |
| 状态机 | 空闲 → 分档（贴放读条 / 投掷飞行）→ 待爆 → 起爆；读条被打断回空闲 |
| 时钟 | **只有一个**：`_process(delta) → tick(delta)`，读条与抛物线都在这里推进（`Charge` 自己不 `_process`），集成冒烟也只用 `tick` 一个入口 |
| 携带量 | `RoleTable.charges_for(role)`：工程兵 2、其余 0（唯一来源） |
| 输出 | 掩体的结构值 / 单位伤害；`Sfx.play("explosion")` + 地面命中特效 |
| HUD | 角色标签追加「爆破 N 发」＋状态（安放中 xx% / 飞行中 / 待起爆）；爆破键文案随状态变（安放中 / 飞行中 / 起爆） |

## 4. 边界条件（都进了测试）

- **超距拒绝**：> 35 m 不起读条也不消耗（集成冒烟拿 500 m 验）；15.1 m 不再拒绝，改走投掷。
- **非工程兵拒绝**：`charges_for == 0` → 提示，不消耗。
- **用完拒绝**：剩余 0 → 提示，不消耗。
- **载具里拒绝**：人在车里 → 提示「下车再放」（步兵炸药与 8.3 的载具发烟器是两条链）。
- **开图拒绝**：战术地图开着时不进入读条（与开火同一条口径）。
- **读条打断**（㊼）：移动 > 0.75 m / 开火 / 挨打 / 倒下 / 开图 / 上车 ⇒ 打断且**不消耗发数**。
- **飞行中不可起爆**（㊻）：按了只给提示，药继续飞。
- **重复起爆**：`placed == null` 时 `detonate()` 什么都不做（幂等）。
- **已倒下 / 已报废的目标**不再吃第二遍伤害（读 `alive` / `destroyed`）。
- **自伤跟模式走**（㊺，2026-10-07 选择题 A）：`MatchRules.friendly_fire()` 为真时把
  `player` / `friendly` / 我方 FOB 一并结算，为假时只打 `enemy` / `fob_enemy`。
  与枪械友伤**同一条规则**，模式表一个字都没改。载具不吃爆炸伤害（接 8.4 部位模型，欠账）。
- **不看开口**：炸药与炮弹一样走「落点圈 ∩ footprint」；窗 / 门洞只约束**直射**弹道（2026-10-03 拍板）。

## 7. 仍未做（欠账）

- 敌方 AI 不会用炸药，也不会躲已经安放的炸药（27.6 ④）。
- 载具不吃爆炸伤害 —— 要接 8.4 的部位模型（按入射面 / 方位权重伤部件）。
- 投掷没有散布（落点 = 准心精确落点）：抛物线只是表现，**预警圈画在哪就落在哪**。
- 「起爆倒计时」（按时自动炸）没做 —— ㊼ 只做了「安放读条」，起爆仍是纯遥控。
- 表里只有 C4 实际在装（TNT 进表未装）。

## 8. 本轮的选择题（2026-10-07，使用者都选推荐档）

1. **自伤口径**：A 跟本局模式走（`MatchRules.friendly_fire()`）—— 不新开口径、模式表零改动。
2. **投掷与贴放共存**：A 近贴远投、不新增按键（≤15 m 贴放、>15 m 抛投，上限 35 m）。
3. **安放倒计时**：A 读条 1.5 s + 纯遥控起爆（中途打断不消耗）。
   ⚠ 第 2 条选项文案里的「瞬时贴放」被第 3 条覆盖：两条拍板冲突时**以「安放倒计时」为准**，
   即贴放是「读条后落地」而不是瞬时。
