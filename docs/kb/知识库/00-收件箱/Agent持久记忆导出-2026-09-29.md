## 2. Godot 4 与运行环境通用坑（跨项目复用）

- **[f016] gdlint**：内部类必须写单行 `class ProbeState extends State:`；写成两行（`class X` 换行 `extends Y`）报 Unexpected token。
- **[f019] 物理回调里不能改碰撞状态**：Area2D.body_entered / CharacterBody2D 碰撞回调里直接 remove_child / 改 collision_layer / monitoring 会被物理空间锁定拒绝（"Can't change this state while flushing queries"）。用 `call_deferred` / `set_deferred`，或等到自己的 `_process`/`_physics_process`。fight-1 对象池归还因此改为延迟执行。
- **[f022] 持久组**：`Node.add_to_group(g, persistent=false)`（默认）在编辑器脚本里对游离节点加的组**不会写进 .tscn**，只有运行时 add_to_group 才生效。生成场景的 EditorScript 必须写 `add_to_group(NAME, true)`，否则 `get_first_node_in_group` 静默失效。出处 `refs/godot-api/Node.md:201-206`。
- **[f024] CanvasLayer 下的 Control size=0**：直接挂 CanvasLayer 下的 Control，`set_anchors_preset(PRESET_FULL_RECT)` 不一定把 size 撑成视口大小 → `_draw` 里 size=(0,0)、绘制跑到左上角。可靠做法：在 `_ready` 与 `Viewport.size_changed` 里显式 `size = get_viewport_rect().size`、`position = Vector2.ZERO` 再 `queue_redraw`。
- **[f062] `_draw` 不会自动清除**：若 `queue_redraw` 写在条件里（「有值才重绘」），从「有」掉到「无」的那一帧必须补一次重绘，否则最后一帧图形永久残留。jieyu-1 敌人压制弧就残留过 20 多秒。写法：用 `_xxx_drawn` 标记上一帧状态，`if 当前 or 上一帧为真: queue_redraw`，再更新标记。
- **[f063] `:=` 类型推断失败会炸整个脚本**：对「动态类型来源」用 `var x := ` 直接报 "Cannot infer the type of x variable..." 并导致脚本加载失败。两类高发来源：① preload 脚本实例的返回值/属性；② Dictionary 索引（`dict["k"]`）再取属性。修法：改 `var x = `（动态）或先标注 `var typed: T = expr`。jieyu-1 里 Main/Vehicle 各踩过一次。排查：`grep -rnE "var [a-z_0-9]+ := .*(\[[^]]*\]|vehicle|_player_ref)" --include=*.gd .`
- **[f056] Camera2D.zoom 语义**：zoom 直接就是「每米多少像素」；默认 1 world unit = 1 屏幕 px。960px 屏幕要可视 60m 必须 `zoom=16`（不是 1.0）。解域三档 zoom=[32,16,8] = 可视 30/60/120m；拖拽换算 = `screen_delta / zoom.x`。曾误设 [2,1,0.5] 导致视野≈全图、角色不可见；`PIXELS_PER_METER_BASE` 是多余抽象，已删。
- **[f012] 导出漏文件**：`.xml` 不是资源，`export_filter=all_resources` 时不打包，必须在导出预设 include_filter（面板 "Filters to export non-resource files/folders"）写 `*.xml`，否则导出后 `XMLParser.open("res://xxx.xml")` 读不到（编辑器里正常）。bradley-mangal-2 的 `export_presets.cfg` 已设 `include_filter="*.xml"`。
- **[f034] Godot 4 导出 Android 官方要求**：OpenJDK 17（推荐）、Android SDK（Platform-Tools 35.0.0+、Build-Tools 35.0.1、Platform 35、cmdline-tools latest、CMake 3.10.2.4988404、NDK r28b 28.1.13356709）；编辑器设置填 Java SDK Path 与 Android SDK Path；上架 Google Play 需 AAB + 非调试 keystore（`keytool -v -genkey -keystore mygame.keystore -alias mygame -keyalg RSA -validity 10000`），导出时取消「使用调试导出」。出处 docs.godotengine.org/zh-cn/4.x/tutorials/export/exporting_for_android.html
- **[f026] /storage/emulated/0 上的 git 会损坏**：media_rw FUSE 文件系统上批量 `git add` 大量文件会产出 0 字节空 loose object（fsck 报 "object corrupt or missing"）。修复：`git ls-tree -r HEAD` 定位缺失 blob 对应文件 → `git hash-object -w <文件>` 强制重写 → `git fsck --full` 验证。注意 `git add` 对内容未变的文件**不会**重写已损坏的 loose object，必须 hash-object -w。

## 3. Agent 自身代码与工具链

- **[f017] server.py 工具分派**：`run_tool(name,args)` 是同步函数，在 `agent_stream` 里经 `await asyncio.to_thread(run_tool, ...)` 调用 → t_shell/t_git/lint_gd 里的 `subprocess.run` 阻塞的是线程池 worker，不阻塞事件循环，`/api/status` 在工具执行期间仍秒回，无需改 create_subprocess_exec。超时上限：shell/git 180s、gdlint 120s。
- **[f018] ~/agent 自身代码约定**：路由不用装饰器，集中写 `app = Starlette(routes=[Route("/api/info", info), ...])`；会话 id 前端变量名 `sid`（localStorage 键 `agent_sid`），后端 chat() 里也是 `sid`；`/api/chat` 用内层 `wrapped()` 生成器 + `StreamingResponse(media_type="text/event-stream")`；顶部已 import asyncio 与 JSONResponse，但**没有** import time。
- **[f014] write_file / edit_file 的 path 坑**：path 是相对项目根 Godot4.7Proj，**不跟随 shell 的 cd**。写子项目必须写全相对路径，如 `"[Squad2D]vehicle-test/PVP/fight-1/xxx.gd"`，否则误写到项目根。
- **[f020] git 工具不支持 -C**：`git` 工具只接受 add/commit/diff 等子命令、不支持 `-C`。操作独立子仓库（如 fight-1）必须走 shell：`cd "[Squad2D]vehicle-test/PVP/fight-1" && git ...`，否则会在项目根执行、误伤其它项目。
- **[f029] docx_vision 坑**：单次调用模型输出有长度上限 → 长文档多次写回时最后一张图的描述会被截断（《[Squad2D]白旗点结构.docx》图3 断在「另外，从」）；prompt 没限制时模型会把内心独白（「让我们仔细看」「我们需要回答用户…」）写进描述并写回文档；描述里的 Markdown `**` 会原样显示在 Word 正文。规避：prompt 明确「只输出最终描述、禁止思考过程、每条不超过 N 字」，并按图片分批调用。

### 5.14 关键算法构思（8 张图）

- **[f031]** 目录 `[Squad2D]关键算法构思`，仅 3 张标【已实现】（准星移动算法、障碍物阻挡检测、高台仰视极限），其余 5 张待实现。**核心数学内核 = 坡度比较「高度差 ÷ 水平距离 = tanθ」**，三处复用：
  - 地形遮挡判定 `(L−h0)/d > (H0+L_T−h0)/D` → 不可视
  - 障碍物阻挡 `(h−h0)/D ≥ tanθ`，`d·tanθ+h0 < H0` → 准星移到红色物体
  - 仰视极限 `D·tanθ ≤ H_max+Δh−h0`，越界则准星回退上一坐标
  - 求最高点 = 射线步进逐格比较高度保留高者；弹道碰撞 = 细长矩形平面碰撞后比高度 `h<H` 或 `h∈[H1,H2]`；弹道表 = 按水平距离等分采样 h1..h12 查表替代积分；x-y 姿态 = 俯视贴图预旋转表现大幅姿态变化。
