# 炸药 / 工程兵（2026-10-04 · 第五十七版）

> 依据：2026-10-04 使用者拍板四条 —— ① 新增兵种「工程兵」（带 2 发）② 准心落点放置（贴墙即可、不要求通视）
> ③ 遥控引爆（再按一次）④ 数值 TNT 2000 / C4 1500。
> 这一块在 docx 里**没有任何独立实体 / 技能表 / 输入映射**（21.2.2 ⑧ 的欠账、22.10 把建筑毁伤降级为后续版本），
> 所以口径全部来自这次拍板；工程侧只负责把它钉死。

---

## 1. 发布说明（玩家能做什么）

- 选「工程兵」开局（兵种键循环到第 4 个），HUD 标签上多出「爆破 N 发」。
- 按「爆破」= 在**准心落点**放一枚炸药（15 m 以内；贴墙 / 贴地都行，**不要求通视**）。
- 再按一次「爆破」= **遥控起爆**：半径内的掩体 / 建筑扣结构值，敌方步兵与工事吃爆炸伤害。
- **一次只能有一枚待爆药**：放了一枚还没炸，再按是引爆而不是再放一枚。
- 非工程兵按它只会得到一句提示；工程兵两发放完也会提示。

## 2. 数值（唯一出口 = `data/config/ChargeTable.gd`）

| 装药 | 结构伤害 | 对人（爆心 / 半径处） | 半径 | 说明 |
|---|---|---|---|---|
| **C4**（默认） | **1500** | 120 / 40 | 8 m | 工程兵默认装药；加固档建筑 3000 正好两发 |
| TNT | 2000 | 160 / 55 | 9 m | 拍板给的更重一档；第一版只进表（换装药改一行数据） |

锚点：一栋**标准建筑（1200）一发 C4 就没了**；加固档（3000）两发；沙袋（200）贴上去必碎。
对比：155mm 间瞄 420、反坦克导弹 800 —— 炸药是「贴上去」的那一档，贵的是**人得走到那儿**。

## 3. 输入 / 状态 / 输出

| 项 | 内容 |
|---|---|
| 输入 | HUD「爆破」键（`ExplosiveButton`，(700,340)）→ `ExplosiveController.toggle()` |
| 状态 | `placed`（待爆的那一枚，`entities/explosive/Charge.gd`）、`used`（本局已放发数） |
| 状态机 | 无待爆 → 放置（消耗 1）；有待爆 → 起爆（不消耗） |
| 携带量 | `RoleTable.charges_for(role)`：工程兵 2、其余 0（唯一来源） |
| 放置距离 | `ExplosiveSystem.PLACE_MAX_M = 15 m`（可以贴脚放） |
| 输出 | 掩体的结构值 / 敌方工事与步兵伤害；`Sfx.play("explosion")` + 地面命中特效 |
| HUD | 角色标签追加「爆破 N 发」（`HudBuilder.update_role()` 实时读控制器，不另存一份） |

## 4. 边界条件（都进了测试）

- **超距拒绝**：> 15 m 不放置、不消耗（集成冒烟拿 500 m 验）。
- **非工程兵拒绝**：`charges_for == 0` → 提示，不消耗。
- **用完拒绝**：剩余 0 → 提示，不消耗。
- **重复起爆**：`placed == null` 时 `detonate()` 什么都不做（幂等）。
- **已倒下 / 已报废的目标**不再吃第二遍伤害（读 `alive` / `destroyed`）。
- **不打自己人**（第一版有意）：爆炸只结算 `enemy` 与 `fob_enemy` 组 ——
  与间瞄只打 enemy 组一致。相反做法会让「贴脸放」等于自杀，而第一版没有救治链。见第八节待拍板。
- **不看开口**：炸药与炮弹一样走「落点圈 ∩ footprint」；窗 / 门洞只约束**直射**弹道（2026-10-03 拍板）。

## 5. 代码落点

| 文件 | 职责 |
|---|---|
| `data/config/ChargeTable.gd` | 弹种表（C4 / TNT）+ 取值函数 —— **唯一数值出口** |
| `systems/explosives/ExplosiveSystem.gd` | 纯逻辑：放置校验 + 对人衰减 + 对建筑衰减（复用 `IndirectFire.structure_blast_at`） |
| `entities/explosive/Charge.gd` | 已放置的炸药节点（程序绘制，不引美术资产） |
| `scenes/gameplay/ExplosiveController.gd` | 输入状态机 + 爆炸结算（Main 的子模块） |
| `ui/HudBuilder.gd` | 「爆破」键 + 角色标签的「爆破 N 发」 |
| `data/config/RoleTable.gd` | 新增 `Role.ENGINEER` + `charges_for()` |
| `test/explosive_test.gd` | 弹种表 / 放置校验 / 两条衰减 / 与间瞄同内核 / 携带量 |
