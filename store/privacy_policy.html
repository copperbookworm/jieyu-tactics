一句话

《解域》默认完全离线运行，不收集你的个人信息；只有你主动开启「AI 参谋」并填入自己的大模型 API 密钥时， 才会在你选定的一局结束后，把该局的战报统计文本发送给你选择的那家模型服务商。

一、我们收集什么

我们不收集：姓名、手机号、通讯录、位置、相册、相机、麦克风、设备标识符（IMEI/IDFA/AAID 等）、 任何用于广告画像的数据。应用没有自建服务器，也不接入任何统计或崩溃上报 SDK。

唯一涉及数据外发的功能是「AI 参谋」（默认关闭，可在设置里开关）：

  • 你需要在应用内自行填入某家模型服务商的 API 密钥；
  • 开启后，一局结束时会生成一段战报摘要（击杀数、占领情况、时长等统计文本）；
  • 该摘要会通过 HTTPS 发送给你选择的那家服务商，用于生成一段复盘文字；
  • 摘要不含姓名、账号、设备标识或任何可识别到你个人的信息。

如果你不填 API 密钥、或不开启该功能，应用不会发起任何网络请求。

二、数据存在哪里

  • 你的 API 密钥与战报摘要保存在你的设备本地（Android 应用私有目录），不上传到我们这里；
  • 卸载应用即删除这些本地数据；应用内也提供清空入口。

三、第三方

AI 参谋会把战报摘要发送给你自行选择的模型服务商（例如 DeepSeek、OpenAI 等）。 这些数据在该服务商侧的处理方式，受该服务商自己的隐私政策约束，与我们无关。

我们不与任何广告、统计、数据分析第三方共享数据。

四、权限

本应用只申请两个 Android 权限，都只服务于上面第一节的 AI 参谋功能：

权限用途
android.permission.INTERNET调用你配置的模型 API
android.permission.ACCESS_NETWORK_STATE发请求前判断当前有没有网络

应用不申请位置、相机、麦克风、通讯录、相册、电话、短信、存储等任何其他权限。

五、费用

AI 参谋产生的接口费用由你在模型服务商处的账户直接结算，我们不参与计费、不经手支付。

六、儿童

本应用不面向 13 岁以下儿童设计，也不会有意收集儿童的个人信息。若你是监护人并认为孩子向我们提供了信息， 请联系上面的邮箱，我们会删除。

七、数据安全

  • 与模型服务商的通信走 HTTPS；
  • 本地保存的 API 密钥做了混淆处理；
  • 由于我们不运营服务器，没有可供泄露的服务端数据库。

八、你的权利与数据删除

你可以随时：① 在应用内关闭 AI 参谋；② 清空本机保存的密钥与战报；③ 直接卸载应用（即删除全部本地数据）。 我们需要说明的是：我们这边没有你的数据可删 —— 应用没有服务端。

九、政策变更

若本政策有实质性变更（例如将来接入联网统计、内购或账号系统），我们会在本页更新「最后更新」日期， 并在应用内以显著方式提示。继续使用即表示你接受更新后的政策。
